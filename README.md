# Quran Portal | بوابة القرآن الكريم

بوابة عربية متجاوبة للمصحف والتلاوات والتفسير والمكتبة والدروس والإذاعة والتقويم والمحفوظات. تعتمد **Next.js 15 App Router وTypeScript** وتُصدّر ملفات HTML ثابتة للنشر على GitHub Pages. تجمع الواجهة بين المتطلبات والتصاميم المرفقة في تجربة موحدة.

## التشغيل المحلي

- تحتاج Node.js 20.9 أو أحدث.
- نفّذ `npm ci` مرة واحدة لتثبيت الحزم من `package-lock.json`.
- نفّذ `npm run dev` ثم افتح `http://localhost:3000`.
- افحص الكود عبر `npm run lint` والأنواع عبر `npm run typecheck`، ثم ابنِ نسخة النشر عبر `npm run build` وشغّل `npm run check:export` للتحقق من ملفاتها ومساراتها.
- يضع Next.js ملفات النشر الثابتة في مجلد `out/`.

## النشر على GitHub Pages

يوجد سير عمل GitHub Actions في `.github/workflows/pages.yml`، ويبني التطبيق ثم يرفع `out/`. من إعدادات المستودع اختر **Settings → Pages → Build and deployment → GitHub Actions**. يضبط سير العمل `basePath` تلقائياً لمستودعات صفحات المشاريع؛ أما مستودع `username.github.io` فينشر على الجذر.

## الأقسام والميزات

- فهرس السور والأجزاء والأحزاب وأرباع الأحزاب وصفحات المصحف، وانتقال مباشر إلى آية. يحفظ القارئ موضع التصفح والخط وتباعد السطور، ويتيح حفظ السور للقراءة دون اتصال.
- تشغيل آية أو نطاق أو سورة كاملة، مع اختيار قارئ من كتالوج Al Quran Cloud، والتكرار والانتقال التلقائي والسرعة ومؤقت الإيقاف. يمكن حفظ صوت الآية بطلب صريح للاستماع دون اتصال. يدعم دليل MP3Quran السور والإذاعات وإعادة محاولة الاتصال، مع عرض الرواية كما وردت في سجل المصدر.
- بحث عربي مطبّع في الأقسام والسور والآيات، مع انتقال مباشر بصيغة `رقم السورة:رقم الآية`، ونسخ الآية أو إنشاء بطاقة صورة لها، ورابط تحليل كلمات الآية في Quranic Arabic Corpus.
- ترجمات معاني القرآن بالإنجليزية والفرنسية والإسبانية والأردية حسب ما يقدمه كتالوج Al Quran Cloud، مع اختيار مصدر التفسير العربي المتاح في الكتالوج.
- صفحة محلية لخطة مراجعة يومية وأسبوعية، وجدولة متباعدة للآيات، وتقييم المراجعة، واختبار ذاتي وشارات تقدم.
- أذكار يومية قابلة للبحث مع عداد تكرار وصوت عند توفره؛ تُحفظ بياناتها وعداداتها محلياً بعد أول تحميل.
- تكرار آية أو نطاق آيات، وتخصيص لون بطاقة المشاركة وحجم خطها، وواجهة مبسطة اختيارية.
- مواقيت الصلاة والتقويم، اتجاه القبلة المحسوب للمدينة المختارة، وعداد تسبيح، وروابط إلى حصن المسلم من مصادره.
- مظهر ليلي ونهاري، إعدادات قراءة وصوت، واجهة مبسطة اختيارية، تثبيت PWA عندما يدعمه المتصفح، وتصدير/استيراد إعدادات الحفظ المحلية.

## البيانات والخصوصية

- يجلب قارئ القرآن النص من [Al Quran Cloud API](https://alquran.cloud/api). تُحفظ السور التي تُقرأ في IndexedDB لتتاح لاحقاً عند انقطاع الاتصال؛ ولا يتضمن المشروع نصاً قرآنياً مكتوباً يدوياً.
- قوائم القراء والإذاعات وروابط البث تأتي من [MP3Quran API](https://www.mp3quran.net/ar/api).
- تحليل الكلمات النحوي والصرفي يفتح [Quranic Arabic Corpus](https://corpus.quran.com/translation.jsp?chapter=2&verse=255) في صفحة خارجية؛ لا يخزن الموقع بيانات التحليل.
- بيانات الأذكار الصوتية والنصية تُحمّل عند الطلب من [Islamic Pro — Azkar API](https://github.com/YousefAsalya/Islamic-Pro-azkar-API) المرخص بترخيص MIT، وينسب المشروع نصوصه إلى حصن المسلم. لا نضمّن بياناته في ملفات الموقع؛ راجع [المصدر المرجعي](https://hisnmuslim.com/i/ar/27) عند اختلاف النص أو العدد.
- مواقيت الصلاة تأتي من [AlAdhan API](https://aladhan.com/prayer-times-api). القيمة الافتراضية طريقة الجزائر `19`، ويمكن اختيار طرق أخرى. قد تختلف المواقيت عن المسجد المحلي.
- المكتبة والدروس توجّهان إلى مواقع المصادر؛ لا نعرض سجلات كتب أو ملفات قبل توثيق المصدر والترخيص.
- المفضلة وآخر قراءة والملاحظات والإعدادات تحفظ محلياً على الجهاز، ولا يوجد حساب أو سجل بحث محفوظ لدى الموقع. عند البحث في الآيات تُرسل عبارة البحث إلى [Al Quran Cloud API](https://alquran.cloud/api)، وعند عرض المواقيت تُرسل المدينة المختارة وطريقة الحساب إلى [AlAdhan API](https://aladhan.com/prayer-times-api).
- لا يطلب التطبيق إذن تحديد الموقع. اتجاه القبلة يحسب محلياً من المدينة المختارة، ومواقيت الصلاة تستخدم المدينة وطريقة الحساب وترسلهما إلى AlAdhan.
- تحفظ السور التي تم فتحها في IndexedDB، ويمكن تنزيل سورة أو آية صوتية بطلب المستخدم لاستخدامها دون اتصال. يقتصر حفظ الآية الصوتية على 200 ملف بحجم لا يتجاوز 12 ميغابايت للملف، ويمكن مسحها من صفحة المحفوظات والإعدادات.
- تصدير النسخة الاحتياطية ينزّل الآيات والسور المفضلة والملاحظات وإعدادات القراءة وخطة المراجعة إلى ملف محلي؛ لا يحتوي ملف النسخة على ملفات الصوت أو بيانات IndexedDB. احتفظ به في مكان آمن.
- نسخة GitHub Pages ثابتة ولا تتضمن تسجيل دخول أو مزامنة سحابية أو لوحة إدارة للمحتوى. هذه الميزات تتطلب خادماً ونظام حسابات منفصلين.
- تعرض قائمة القراء الروايات بحسب أوصاف MP3Quran فقط. تغيير قارئ الصوت لا يغيّر رسم المصحف، ولا توفر النسخة خيار رواية نصية مثل ورش ما لم يتوفر لها مصدر نص موثوق ومعتمد.

## ملفات المشروع

- `src/app/`: جذر Next.js وواجهة الصفحة.
- `public/assets/`: سكربت التطبيق والأيقونة.
- `public/service-worker.js`: تخزين هيكل الموقع مؤقتاً.
- `manifest.webmanifest`: بيانات تثبيت الموقع كتطبيق ويب.
- `scripts/check-export.mjs`: فحص وجود الملفات ومسارات HTML بعد التصدير.
- `next.config.ts`: التصدير الثابت و`basePath`.
- `.github/workflows/pages.yml`: البناء والنشر.
- `docs/reference-summary.md`: خلاصة منقحة لمتطلبات الدمج ومصادر البيانات.

## المساهمة

المساهمات مرحب بها عبر Issues وPull requests في مستودع GitHub. راجع `docs/reference-summary.md` لمتطلبات الدمج ومصادر البيانات.
